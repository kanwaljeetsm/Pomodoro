<h2 align="center">With the Pomodoro Android app you can work more effectively during the Work sessions and take breaks at regular intervals without worrying about the timings, focusing on what's important - Work </h2>

<h3><u>Features of Pomodoro App:</u></h3>

1. Effectively work during Work Sessions and take breaks in Break Sessions
2. Aesthetic circular timer to keep track of time left
3. Background running timer so that session can be recorded even when app is killed
4. Set Session name to record the activity done
5. Add detailed notes to mention the activities covered/pending in the session
6. Recorded date-time of the session divided on daily basis on History Page
7. Screen Awake option to keep screen lit on Homepage (turned off by default)
8. Light/Dark theme based on system settings
